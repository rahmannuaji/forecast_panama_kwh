Uji Diebold-Mariano

H0: akurasi kedua model sama. Kerugian = rata-rata galat absolut harian; varians HAC Newey-West lag 5; DM < 0 berarti model A lebih akurat.

Ramalan 24 jam setelah akhir data

Chronos-2 univariat yang dimuat dari folder lokal meramal 27 Juni 2020 pukul 01.00 sampai 28 Juni 2020 pukul 00.00. Nilai cuaca masa depan tidak tersedia, sehingga varian berkovariat tidak dipakai di sini.

Metodologi dan keterbatasan

Desain evaluasi

Ukuran akurasi: MAE, RMSE, MAPE, MASE (skala seasonal naive 168 jam pada data latih), WQL rata-rata kuantil 0,1 sampai 0,9, dan cakupan interval 80%.

Keterbatasan

Kovariat cuaca memakai nilai observasi, bukan ramalan cuaca, sehingga akurasi model berkovariat adalah batas atas. Foundation model tidak di-fine-tune. Hiperparameter XGBoost dan orde ARIMA tidak dicari secara grid. Evaluasi mencakup satu semester (Januari s.d. Juni 2020).
